# 旅游攻略自动生成器

一个开箱即用的单页行程规划工具。填写目的地、日期、天数、人数、预算和兴趣偏好，即可生成包含时间线、交通、酒店、门票与预算明细的旅行攻略。

## 特点

- 纯静态页面，无需后端与构建步骤，双击 `index.html` 即可使用
- 所有计算与数据都在浏览器本地完成，不上传任何个人信息
- 支持打印 / 存为 PDF，也可导出一份独立的 HTML 攻略
- 内置常用目的地与景点参考数据，未收录城市按通用模板生成

## 本地使用

直接用浏览器打开 `index.html`。

## 在线访问

通过 GitHub Pages 发布，访问仓库对应的 Pages 地址即可。

## 说明

页面内置的门票、时长、距离、酒店与餐饮价格均为参考估算值，实际请以景区与商家官方公示为准。
